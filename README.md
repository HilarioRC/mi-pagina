# Mi Página

Portafolio personal de Hilario Reyes Cabello, estudiante de Licenciatura en Administración con enfoque en desarrollo de software.

## Descripción

Este proyecto es una aplicación web MVC desarrollada con Spring Boot 3.2.0 que presenta mi perfil profesional como desarrollador backend. El sitio incluye:

- **Inicio**: Presentación personal con enfoque en desarrollo de software, análisis de datos y procesos empresariales
- **Sobre mí**: Información detallada sobre mi formación, habilidades técnicas (Java, Spring Boot, PostgreSQL, Oracle PL/SQL, Git, Docker) y objetivos profesionales
- **Proyectos**: Sección dedicada a mis proyectos, actualmente incluye:
  - Finance Blog (en construcción)
- **Contacto**: Enlaces de contacto profesional (email, LinkedIn, GitHub)

## Tecnologías

- Java 17
- Spring Boot 3.2.0
- Thymeleaf (plantillas HTML)
- Maven
- Docker

## Ejecución

```bash
mvn spring-boot:run
```

La aplicación estará disponible en `http://localhost:8080`
